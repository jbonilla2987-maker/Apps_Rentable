# Publicar RutaRentable Unificado en GitHub Pages

1. Descomprime el paquete.
2. Entra al repositorio `rutarentable-pro-demo`.
3. Selecciona **Add file > Upload files**.
4. Sube directamente:
   - `index.html`
   - `manifest.webmanifest`
   - `service-worker.js`
   - `.nojekyll`
   - `404.html`
   - `README.md`
   - la carpeta `icons`
5. Presiona **Commit changes** una sola vez.
6. En **Settings > Pages** conserva `main` y `/(root)`.

No subas el ZIP sin descomprimir.
