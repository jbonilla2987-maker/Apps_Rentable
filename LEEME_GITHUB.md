# Publicar RutaRentable PRO 3.4 en GitHub Pages

1. Sube el contenido de esta carpeta a tu repositorio de GitHub.
2. Ve a **Settings > Pages**.
3. Selecciona la rama que usas y **/(root)**.
4. Guarda y espera a que GitHub publique.
5. En **Firebase Console > Authentication > Settings > Authorized domains**, verifica que esté el dominio de GitHub Pages donde publicas RutaRentable.
6. En **Firebase Console > Firestore Database > Rules**, pega y publica `FIRESTORE_REGLAS.txt`.
