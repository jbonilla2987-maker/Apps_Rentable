RutaRentable PRO 3.6.9 - WEB

Cambios sobre 3.6.8:
- El GPS del navegador móvil se activa automáticamente al iniciar una jornada.
- El GPS se detiene automáticamente al finalizar la jornada.
- Si se vuelve a abrir RutaRentable con una jornada activa, intenta reanudar el rastreo automáticamente.
- El mapa del administrador mantiene estado En línea/Señal reciente/Desconectado, velocidad, precisión y última señal.
- En Usuarios, el administrador tiene botón 📥 JSON para descargar el respaldo de cada cuenta directamente desde Firestore.
- Las reglas de Firestore permiten al administrador solo LECTURA de los datos de otros usuarios para generar el respaldo; no le conceden escritura sobre esos datos.

IMPORTANTE:
- Publica firestore.rules junto con la web.
- En web móvil, el navegador debe tener permiso de ubicación y la página debe usar HTTPS.
